## Featured Projects

### Hydrogen Explosion Dynamics in Complex Geometries

CFD–experiment validation of hydrogen deflagration in congested geometries using a hydrogen-capable PDRFoam workflow.

- OpenFOAM
- PDRFoam
- Hydrogen combustion
- Overpressure validation
- Solver development

🔗 [View my portfolio project](https://ashok212422.github.io/#projects)

### Incense-Stick Turbulent Flow Analysis

A MATLAB workflow using Farneback optical flow to analyse apparent plume motion, probe velocities, two-dimensional turbulent kinetic energy, Reynolds stresses, spectral characteristics, vorticity and plume spreading.

🔗 [View repository](https://github.com/ashok212422/incense-stick-turbulent-flow-analysis)

### Marine Engine Cylinder-Liner Thermal Analysis

A Python and TensorFlow research prototype using a physics-informed neural network to study an idealized steady temperature field in a marine-engine cylinder liner.

🔗 [View repository](https://github.com/ashok212422/marine-engine-cylinder-liner-pinn)

### Optical-Flow-Based Combustion Diagnostics

A scientific-computing workflow using SEA-RAFT to extract time-resolved apparent motion from combustion images and compare flow structures with CFD velocity fields.

🔗 [View GitHub repositories](https://github.com/ashok212422?tab=repositories)
